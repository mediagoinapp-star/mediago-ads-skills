# Support, diagnostics, and privacy boundary

The Skill must not upload source code, complete Logcat output, App IDs, placement IDs, credentials, or internal URLs.

For troubleshooting, request the smallest useful evidence: SDK/adapter version, error code/message, integration path, format, and a redacted log excerpt. If a future MCP diagnostic tool is available, call it only after the customer explicitly approves sending the shown, minimized data.

Public releases should state the support channel, supported versions, known limitations, and changelog location. Technical integration guidance is not legal advice or a claim of privacy/store-policy compliance.
