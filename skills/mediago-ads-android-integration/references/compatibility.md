# Compatibility maintenance

Before each public release, verify examples against the current approved MediaGo SDK and adapter versions. Record:

- skill release version and date;
- minimum/verified MediaGo SDK version;
- verified AdMob, MAX, TradPlus, TopOn international, and TopOn legacy adapter versions;
- Android `minSdk` and `compileSdk` baseline;
- documentation source revision and reviewer.

Do not publish placeholder adapter class names, dynamic-version recommendations, credentials, private endpoints, or internal documentation URLs. If a public release does not have a validated compatibility entry, state the limitation rather than guessing.
