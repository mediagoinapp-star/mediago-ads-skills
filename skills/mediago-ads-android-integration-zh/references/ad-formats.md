# 广告样式

生成代码前先阅读对应章节。使用客户真实广告位 ID；只有用户明确要求测试时才使用测试参数。

## 开屏

`SplashAd` 支持先加载后展示，以及文档规定的一步式加载展示。展示需传入 `ViewGroup` 容器。加载失败和全屏关闭后均应继续宿主应用启动流程；广告不再使用时销毁。

## 插屏

加载 `ExpressInterstitialAd`，成功后缓存实例；仅当广告 ready 且 Activity 有效时调用 `show(Activity)`。关闭或展示失败后清空/销毁引用，并使应用继续业务流程。

## 激励视频

加载 `RewardedAd`，仅在 ready 且由有效 Activity 发起时展示。业务奖励只能在 `OnUserEarnedRewardListener` 中发放，不能由曝光、点击或关闭事件推断奖励。关闭或展示失败后清空/销毁。

## Banner

按文档创建 Banner 对象与容器，并绑定至页面生命周期。宿主 View 永久移除时显式销毁。排查空白 Banner 前先检查宽高和容器要求。

## Native

使用 `NativeAdLoader` 加载。仅渲染支持的素材字段，然后通过 Native 交互 API 注册根 View 和允许点击的子 View。除非 API 明确允许，不要把披露、dislike、媒体或非点击区域加入可点击列表。列表项或页面销毁时释放 Native 广告对象。

## 通用回调

全屏广告应在 show 前设置回调。至少处理展示、曝光、点击、关闭和展示失败；支持时，落地页回调独立处理。每个终态回调都必须包含业务兜底和引用清理。
