# 迁移与升级

SDK/Adapter 升级、旧 API 替换或直连与 Adapter 路径切换时使用本文件。

## 变更前

盘点目标模块已解析的 SDK/Adapter 版本、现有初始化、广告样式、Manifest 定制、ProGuard/R8 文件和测试/生产凭证处理方式。展示升级计划，在编辑或执行依赖命令前请求确认。

## 迁移清单

- 仅修改已批准的依赖声明；不得手改生成的 lock/cache/解析输出；
- 升级后重新检查直连与 Adapter 的初始化归属；仅在选定路径文档要求时移除重复初始化；
- 重新验证所有广告样式回调，尤其是激励发放和终态清理；
- 重新验证 Manifest Activity/进程覆盖与 R8 规则；
- 构建目标 Variant，检查依赖和 manifest-merger 输出；
- 在设备上完成所选广告样式的回归检查后，才能报告真机已验证。

## 完整性复核

逐行替换 API 不足以完成迁移。还需确认加载触发、ready 检查、无效 Activity、销毁/清理、隐私设置时机、测试配置隔离和业务兜底。若升级跨越了未验证的兼容性边界，停止并要求提供已批准的目标版本。
