# 验收清单

仅执行与客户选择路径和广告样式相关的检查。

## 所有接入

- 目标 App Variant 已解析到批准的 SDK/Adapter 组合；
- 仅存在预期的一位初始化责任方；
- 客户生产凭证未被测试参数替换；
- 构建通过，Manifest merger 无未解决冲突；
- 加载失败后宿主应用保持正常业务流程。

## 全屏广告

- 初始化/ready 前置条件满足后才加载；
- 仅从存活、未 finishing、未 destroyed 的 Activity 展示；
- 处理展示、曝光、点击、关闭和展示失败；
- 在文档规定的终态清空/销毁缓存实例。

## 激励视频

- 仅在奖励回调中发奖；
- 同一次展示不可重复发奖；
- 关闭或展示失败不得发奖。

## Banner 与 Native

- Banner 容器满足布局尺寸要求，并随宿主销毁；
- Native 仅渲染支持的素材字段；
- Native 根 View/可点击 View 按文档注册；
- Native 对象随列表项/页面生命周期释放。

## 证据报告

说明哪些检查已观察到、哪些仅构建验证、哪些还需要客户真机/后台确认。未实际观察到广告填充或曝光时，不得标记为已验证。
