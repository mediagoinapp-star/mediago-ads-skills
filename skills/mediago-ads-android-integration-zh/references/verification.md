# 验证标准

## 证据级别

准确说明结果：

1. **已规划**：尚未修改工程；
2. **已应用变更**：文件已修改，尚未构建；
3. **构建通过**：已批准的 Gradle 任务成功完成；
4. **真机已验证**：测试人员在设备上观察到预期加载、展示和回调行为。

## 测试参数

仅当客户明确要求测试、Demo 或验证，且未提供适用凭证时，才使用官方 MediaGo 测试参数。每次使用均标记为仅测试，并在生产构建前删除或隔离；默认不要将参数提交至源码。

## 最小样式验证

针对所选广告样式，验证初始化、加载成功或可行动失败、展示资格、展示/关闭或 Native 交互回调，以及宿主应用的失败兜底。激励视频还必须确认奖励仅在奖励回调中发放。
