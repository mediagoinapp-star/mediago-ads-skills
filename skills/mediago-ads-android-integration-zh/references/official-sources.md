# 官方资料与事实优先级

事实冲突时，按以下优先级处理：

1. 本仓库或其对外替代地址中，已通过发布审批的 MediaGo 兼容矩阵；
2. 带版本的 MediaGo Android 对外接入文档；
3. 与已解析版本完全一致的公开 SDK/API 产物；
4. 客户工程中的实际证据；
5. 通用知识只能用于非版本化解释；不得用于 API 签名、Adapter 类名、依赖坐标或兼容性结论。

公开 Skill 必须内置或链接经过审核且外部可访问的资料。

## 发布前必须核验的事实

每个受支持的 SDK/Adapter 版本都要核验并记录：

- Maven 坐标和版本策略；
- MediaGo API 签名与回调语义；
- 必需/可选 Manifest 配置；
- Adapter 类名和后台配置参数；
- Android / AGP / Gradle / JDK 支持基线；
- 错误码建议和测试配置策略。

若已批准资料中没有准确事实，应说明“尚未验证”，不得猜测。
