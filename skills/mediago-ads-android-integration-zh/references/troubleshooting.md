# 问题排查

收集准确的 SDK/Adapter 版本、完整错误码/错误信息、直连或聚合路径、广告样式、已脱敏的 App/广告位标识、初始化时机，以及相关构建或 Logcat 证据。

常见检查：

- 未初始化：确认首次直连请求前 `AdMaster.initialize` 已成功；
- 网络问题：检查设备网络，不添加不必要权限；
- 配置无效：与客户后台负责人核对 App/广告位标识，不在输出中泄露；
- 正在加载：避免同一逻辑广告位的并发重复加载；
- Activity 已销毁：仅从存活、未 finishing、未 destroyed 的 Activity 展示；
- 展示失败或广告过期：清空引用、继续业务流程，并在适当时机重新加载；
- 无填充：报告 SDK 实际返回错误，不编造统一 no-fill 常量，也不能仅凭无填充判断 SDK 接入成败；
- Gradle/Manifest 失败：获得运行命令许可后，检查完整依赖图或 manifest-merger 输出。
