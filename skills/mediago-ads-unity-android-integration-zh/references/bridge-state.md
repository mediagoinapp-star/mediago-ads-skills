# Bridge 状态与硬门禁

维护：Unity/团结版本与 Android 目标、`direct-bridge | client-bidding-bridge | approved-adapter-bridge` 路径、EDM 声明/生成证据/批准版本、Template、C# Bridge/Java 类/回调接口/主线程调度及验证等级。

硬门禁：确认 Android 目标；识别可编辑事实源文件；确认唯一接入路径；在生成版本特定 Bridge 代码前验证已批准 SDK/Adapter 版本；在 Resolve/导出/构建/编辑前获得计划确认。

不得编辑 `Library/` 或生成 Gradle 输出。若生成输出与 Template 不一致，先报告差异并检查生成配置。
